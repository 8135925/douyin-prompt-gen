# 抖音口播视频一键生成小工具 · 需求说明书

## 一、项目背景与目标

参考开源项目  的技术路线（浏览器自动化 + 本地桌面小工具 + 可视化任务进度），做一个**本地运行的抖音口播视频一键生成小工具**。

用户只需提供「标题、抖音链接、口播文案」三项输入，工具即可自动完成：抖音音频提取 → 目录归档 → 生成标准化发布提示词，最终把一段可直接复制使用的高质量提示词交给用户，用于驱动具备 `vibe-knowledge-file` 能力的模型生成成品视频。

## 二、技术参考

- 参考 RuiC-oc-ferry ( https://github.com/HRuiCcc/RuiC-oc-ferry )的思路界面做成类似的，用于自动化操作第三方下载站点。
- 本地 GUI 采用美观的桌面界面（具备进度条 + 实时日志面板）。

## 三、用户输入（Step 1：信息采集）

界面需提供三个输入项，其中两项为核心变量：

| 名称 | 变量占位符 | 输入方式 | 说明 |
| --- | --- | --- | --- |
| 标题名字 | `{{变量1}}`（即 `{{TITLE}}`） | 文本框 | 例：`认知复利`。用于文件夹名、音频文件名、视频标题、封面主题。 |
| 抖音链接 | — | 文本框 | 用户粘贴抖音分享文本，例：`8.28 复制打开抖音，看看【木读精进史的作品】... https://v.douyin.com/nZz3COvjqoI/ ...`。**工具需自动从整段文本中提取出 `https://v.douyin.com/...` 短链**，忽略其余复制口令噪声。 |
| 口播文案 | `{{变量2}}`（即 `{{COPY}}`） | 多行文本框 | 最长支持 20000 字。例：`真正的学习，从第四遍才开始，反复的梳理是对知识的不断打磨和提炼。` |

输入校验：三项均为必填；`{{变量1}}` 需过滤 Windows 非法文件名字符（`\ / : * ? " < > |`）；`{{变量2}}` 超过 50000 字时给出提示并截断或阻止提交。

## 四、自动化处理流程（Step 2：一键执行）

用户点击「开始」后，按以下顺序自动执行，每一步在进度条与日志面板中体现：

**步骤 2.1 —— 创建工作目录**
在 `C:\Users\ASUS\Documents`（应设计为可配置的用户文档根目录，不写死）下创建以 `{{变量1}}` 命名的新文件夹，例如 `C:\Users\ASUS\Documents\认知复利`。若已存在则复用，不报错。

**步骤 2.2 —— 提取并归档音频**
1. 用浏览器自动化打开 `https://vidgap.com/douyin/audio/cn`。
2. 将提取出的抖音短链粘贴到输入框，点击「下载」按钮。
3. 捕获下载得到的 mp3 文件（通常文件名为一长串随机字符）。
4. 将该 mp3 移动（剪切）到工作目录，并重命名为 `{{变量1}}.mp3`，最终路径形如：`C:\Users\ASUS\Documents\认知复利\认知复利.mp3`。
5. 下载/移动失败需捕获异常并记录日志，提示用户检查链接有效性或站点可用状态。

**步骤 2.3 —— 生成发布提示词**
将下方「发布提示词模板」中的 `{{变量1}}`、`{{变量2}}` 替换为实际值，得到成品提示词。

**步骤 2.4 —— 输出成品提示词**
把替换完成的完整提示词展示在一个可一键「复制」的文本框中，供用户复制后驱动模型生成视频。

## 五、发布提示词模板（含变量）

> 以下为模板原文，`{{变量1}}` = 标题、`{{变量2}}` = 口播文案，运行时自动替换。

```
我要参加抖音上的 Vibe知识大赏
请调用 vibe-knowledge-file 这个 skill 生成一条抖音发布视频，具体参数与要求如下：

**1. 音频配置**
- 背景音乐：C:\Users\ASUS\Documents\{{变量1}}\{{变量1}}.mp3
- 音画同步：视频总时长必须等于音频时长，不要裁剪音频，不要延长或缩短音频，音频结束时画面自然收尾，不要突然黑屏，画面、字幕、音频三者时间轴严格对齐。（画面、字幕、音频三者时间轴严格对齐 ×3）
- 字幕文字：字幕文字必须与提供的文案文本完全一致，不得改写；每一句字幕的末尾绝对不带任何逗号、句号等标点符号，确保视觉上的干净利落与绝对对齐。

**2. 视觉规范**
- 封面输出：同时生成横屏 cover_h.png（1441×1080）与竖屏 cover_v.png（1080×1441）。
- 水印设置：水印「陆壹」在右下角，20px、20% 不透明度，全片常驻（片尾淡出）。

**3. 发布物料**
- 自动生成适配抖音平台的标题（固定为 Vibe知识大赏 | {{变量1}}）与简介文案。标题为 {{变量1}}，封面主题同样使用 {{变量1}}。

**4. 视频文案内容**：
{{变量2}}

**5. 输出归档**
最终生成的视频、封面、发布抖音的 markdown 文件，均复制一份到 C:\Users\ASUS\Documents\{{变量1}} 目录下。
```

**填充示例（变量1=认知复利，变量2=真正的学习…）：**
背景音乐路径变为 `C:\Users\ASUS\Documents\认知复利\认知复利.mp3`；标题变为 `Vibe知识大赏 | 认知复利`、标题与封面主题均为 `认知复利`；第 4 项填入完整口播文案；第 5 项归档目录变为 `C:\Users\ASUS\Documents\认知复利`。

## 六、界面与交互要求（Step 3）

- **美观现代**：简洁卡片式布局，配色协调，留白得当。
- **任务进度**：以进度条 + 步骤编号（2.1～2.4）清晰展示当前所处阶段，让用户随时知道进行到哪一步。
- **实时日志面板**：提供独立滚动日志框，实时打印每一步操作（打开网页、粘贴链接、点击下载、捕获文件、重命名、替换变量、生成提示词等），日志要足够详细、时间戳 + 操作说明，便于排查问题。
- **成品提示词区**：可一键复制，长文本可滚动查看。

## 七、异常与边界处理（建议实现）

- 抖音短链提取失败 → 明确提示"未检测到有效抖音链接"。
- 下载站点超时/改版/无下载按钮 → 捕获并提示，允许重试。
- 文档根目录无写入权限 → 提示切换目录。
- 变量含非法文件名字符 → 自动清洗并告知清洗结果。
